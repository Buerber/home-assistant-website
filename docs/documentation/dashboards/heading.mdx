## 标题徽章 

除了标题文本外，每个标题卡片还可以显示小徽章。它们比常规[徽章](https://www.home-assistant.io/dashboards/badges/)更小，且没有背景。标题徽章可以以紧凑和简约的风格显示传感器信息。标题徽章也支持[操作](/docs/documentation/dashboards/actions)。

```yaml
type: entity
entity: light.living_room
```
