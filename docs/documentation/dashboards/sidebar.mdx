# 侧边栏视图

<p className="text-xl font-semibold">
侧边栏视图有2列，一个宽列和右侧的一个较小列。
</p>
![能源仪表板使用的侧边栏视图截图。](./img/sidebar_1.png)
<p className="text-center font-extralight">能源仪表板使用的侧边栏视图截图。</p>

要将卡片从主列移动到侧边栏（右侧）（反之亦然），选择卡片上的箭头 <ArrowBigLeft className='align-middle inline ' size={18}  /> <ArrowBigRight className='align-middle inline ' size={18}  /> 按钮。

![显示移动卡片的箭头按钮的截图。](./img/sidebar_2.png)

在移动设备上，所有卡片都以1列渲染，并按照YAML配置中指示的顺序保持。

1. 要查看YAML配置，在视图选项卡上，选择 <Pencil className='align-middle inline ' size={18}  /> 图标打开编辑视图。
在配置对话框中，选择三点菜单，然后选择**在YAML中编辑**。

![显示在哪里编辑视图配置的截图。](./img/sidebar_3.png)

### 示例

卡片的位置使用YAML中的`view_layout`选项进行配置：

```yaml
type: sidebar
cards:
  - type: entities
    entities:
      - media_player.lounge_room
    view_layout:
      position: sidebar
```
