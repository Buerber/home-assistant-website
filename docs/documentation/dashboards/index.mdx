# 仪表板主界面

<p className="text-xl font-semibold">
Home Assistant仪表板允许你显示关于智能家居的信息。仪表板可以自定义，并提供了强大的方式来通过移动设备或桌面管理你的家。
</p>

你可以使用各种选项自定义你的仪表板：

- 不同的卡片类型来可视化你的数据并控制你的智能家居设备。
- [主题](https://www.home-assistant.io/integrations/frontend/#defining-themes)（甚至可以按卡片单独设置）。
- 覆盖实体的名称和图标。
- 使用来自我们出色社区的自定义卡片。

![屏幕录像展示如何在分区视图中编辑仪表板以及如何重新排列卡片](./img/section_view_rearrange_cards.gif)

## 探索交互式演示仪表板

通过[交互式演示](https://demo.home-assistant.io/)亲自尝试。

## 开始创建你自己的仪表板

要创建你自己的仪表板，请按照[创建新仪表板](/docs/documentation/dashboards/multiple-dashboard#创建新仪表板)中的步骤操作。
